How To Read It

Blue flows change files in the local workspace.
Amber flows prepare or unprepare changes for a commit.
Green flows create, inspect, or reshape local history.
Red flows exchange commits with the shared remote.
Violet flows temporarily store work without committing it.
Short loops show commands that act inside one Git area.

Beginner Daily Path

  1. 1Sync first with git pull.
  2. 2Edit files in your workspace.
  3. 3Prepare changes with git add.
  4. 4Save locally with git commit.
  5. 5Share work with git push.
