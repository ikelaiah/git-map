Interactive Git Helper

Hover or focus a Git area to see the commands that move changes between stash, workspace, staging, local history, and a remote repository.

Stash Local Workspace Staging Area Local Repo Remote Repo
S

Stash

Temporary shelf for unfinished work you want to hide and restore later.

git stash
W

Local Workspace

Your checked-out files. This is where edits, new files, conflicts, and deletions appear first.

git status
A

Staging Area

The prepared snapshot for your next commit. Add only what belongs together.

git diff --staged
L

Local Repo

Your local commit history. Commits are saved here before they are shared.

git log --oneline
R

Remote Repo

The shared copy on GitHub, GitLab, Bitbucket, or another Git server.

git remote -v

How To Read It

Blue flows change files in the local workspace.
Amber flows prepare or unprepare changes for a commit.
Green flows create or inspect local commits.
Red flows exchange commits with the shared remote.
Violet flows temporarily store work without committing it.

Beginner Daily Path

  1. 1Sync first with git pull.
  2. 2Edit files in your workspace.
  3. 3Prepare changes with git add.
  4. 4Save locally with git commit.
  5. 5Share work with git push.
